# Captain

Captain is a clean, responsive layout built to explore CSS structure, spacing, and visual hierarchy. It focuses on clarity, balance, and consistent styling across sections.

## Purpose
This project serves as a front‑end design exercise, demonstrating how thoughtful CSS can create a polished, readable layout without relying on frameworks.

## Features
- Responsive design
- Structured layout sections
- Clean typography
- Consistent spacing and rhythm
- Pure CSS styling

## Tech Stack
- HTML
- CSS

## Live Demo
https://badwolf910.github.io/Captain/

## Project Goals
- Strengthen CSS layout and styling skills
- Practice responsive design fundamentals
- Build a visually cohesive page using minimal tools
